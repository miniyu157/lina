## 发行版源仓库格式规范 v1(原 v3.3)

### 仓库结构

```plaintext
<REPO>
  INDEX         # 仓库索引，JSON 格式
  dir/          # 存储发行版小程序
    alpine.sh
    ubuntu.py
    ...
  ... # 其他存储发行版小程序的文件夹
  build_INDEX   # 仓库索引生成工具
  validate      # 索引验证工具，能根据索引进行抽样检测，例如对小程序传入随机的发行版数据，测试网络
```

### 发行版小程序

通过子命令模式调用，输出各个信息到 stdout

子命令 `info`:

```json
{
  "name": "",       // 发行版名称。例如 ubuntu
  "desc": ""        // 单行描述。例如 Ubuntu Base
}
```

子命令 `options`:

```json
{
  "archs": [""],      // 架构选项。例如 aarch64, x86_64
  "versions": [""],   // 版本选项，从新到旧排序
  "mirrors": [        // 源列表，存储镜像站文件结构的前缀，例如 https://mirrors.ustc.edu.cn/ubuntu-cdimage/
    ""
  ]
}
```

子命令 `get <version> <arch> [mirror]`:

```json
{
  "src": "",
  "hash_val": ""
}
```

- src: 传入 options 后传出的镜像直链。
- hash_val: 为文件校验值，格式为 "算法:Hex字符串"，或者 "SKIP"，表示跳过完整性验证。

### 发行版小程序 bash 模板

```bash
#!/usr/bin/env bash

# shellcheck shell=bash

set -euo pipefail
shopt -s inherit_errexit 2> /dev/null || true

info() {
    cat << 'EOF'
{
  "name": "<NAME>",
  "desc": "<DESCRIPTION>"
}
EOF
}

options() {
    # 也可以动态生成

    cat << 'EOF'
{
  "archs": ["<ARCH>", "..."],
  "versions": ["<VERSION>", "..."],
  "mirrors": ["<MIRROR_URL>", "..."]
}
EOF
}

get() {
    local default_mirror='<DEFAULT_MIRROR_URL>'
    local version="${1}" arch="${2}" mirror="${3:-$default_mirror}"
    [[ -z $version || -z $arch ]] && usage

    # 不要校验参数，此函数由机器调用。

    # TODO: fetch and compute src, hash_val
    # hash_val 格式: "算法:hex字符串" 或 "SKIP"
    # 你可以解析镜像源的 sums 文件，也可以直接下载对应的 sum 直链文件。

    # 遇到异常使用 printf 打印报错信息，重定向到 stderr，然后执行 return 1 退出

    cat << EOF
{
  "src": "${src}",
  "hash_val": "${algo}:${hash_val}"
}
EOF
}

usage() {
    echo "usage: $0 {options | info | get <version> <arch> [mirror] }" >&2
    exit 1
}

main() {
    case "${1:-}" in
        options)
            options
            ;;
        info)
            info
            ;;
        get)
            get "${2:-}" "${3:-}" "${4:-}"
            ;;
        *) usage ;;
    esac
}

[[ ${BASH_SOURCE[0]} == "${0}" ]] && main "$@"
```

### INDEX 仓库索引

INDEX 文件为 JSON 文档，由脚本统一生成。

```json
{
  "version": "",        // 版本标识符，例如 v21、v8-previre 等任意字符串。
  "entries": [          // 小程序 info 命令输出，直接加入到 entries 数组中
    {
      "name": "alpine.bbe502c",   // 把 info 输出的 name 字段，追加小程序文件内容的短 hash
      "desc": "Alpine Linux",
      
      "exec": {          // exec 表示小程序相关的信息
        "file": "distros/alpine.sh",    // 小程序的文件的相对路径
        "options": {     // 小程序 options 命令输出，原封不动嵌套到 options 对象中。
          "archs": ["aarch64", "x86_64"],
          "versions": ["latest-stable"],
          "mirrors": [
            "https://mirrors.tuna.tsinghua.edu.cn/alpine/",
            "https://mirrors.aliyun.com/alpine/",
            "https://dl-cdn.alpinelinux.org/alpine/"
          ]
        }
      }
    }
  ]
}
```

### 新增发行版

1. 创建 `<dir>/<filename>`，按上述契约实现必要的子命令
2. 使用 build_INDEX、validate 等工具验证
3. 使用 build_INDEX 重新生成仓库索引文件
